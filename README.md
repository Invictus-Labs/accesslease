# AccessLease

Make temporary task access expire, and prove revocation.

**Status: pre-MVP, under development.** Nothing in this repository is a release. The product contract is [docs/prd/accesslease.md](docs/prd/accesslease.md).

- License: MIT
- Runtime: Node.js 22+, TypeScript API and worker, PostgreSQL, React lease view
- Standalone: no account, license server, telemetry or paid provider is required.

This README is replaced with installation and operator documentation as the MVP lands.
